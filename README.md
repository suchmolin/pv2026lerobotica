# pv2026lerobotica

Landing page de **Lerobotica** — React + Vite + Tailwind CSS v4.

## Inicio rápido

```bash
npm install
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173).

## Assets

Las imágenes van en `src/assets/images/`. Ver [src/assets/images/README.md](src/assets/images/README.md) para rutas y cómo reemplazar placeholders.
